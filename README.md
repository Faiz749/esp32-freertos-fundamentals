# ESP32 FreeRTOS Fundamentals

This repository contains my FreeRTOS learning journey using the ESP32. I started this to understand how real-time operating systems work in embedded systems and to build on the ESP32 and C fundamentals I already had. The goal of this repository is to learn FreeRTOS step by step through small practical projects.

## What this repository covers

This course covers important FreeRTOS concepts such as:

* Tasks
* Task scheduling
* Task priorities
* Task delays
* Task handles
* Race conditions
* Mutexes
* Semaphores
* Queues
* Event groups
* Task notifications
* Software timers
* Task communication

## Project list

* Day 1: FreeRTOS Tasks
* Day 2: Task Scheduling and Priorities
* Day 3: Race Conditions
* Day 4: Mutexes and Semaphores
* Day 5: FreeRTOS Queues
* Day 6: FreeRTOS Queues
* Day 7: Event Groups
* Day 8: Software Timer and Task Notifications

## Why I made this repository

I made this repository to build a proper understanding of FreeRTOS through practical examples. Instead of only learning the functions and terminology, I created small projects to understand how tasks communicate, synchronize, and run together.

## Embedded systems relevance

FreeRTOS is commonly used in embedded systems where multiple operations need to run independently and respond to events.

The projects in this repository practice ideas such as:

* Running multiple tasks
* Controlling task timing and priorities
* Sharing resources safely
* Passing data between tasks
* Responding to events
* Running periodic system operations

This repository is preparation for larger ESP32 and embedded RTOS projects.
